## 做了什么

两台 web 机器用 Docker 跑 Nginx + PHP + MariaDB，再加 Keepalived 做 VIP 漂移，
一台挂了另一台接过来，外面只认一个 IP。

```
                  （浏览器测试）
                        │
                        ▼
              VIP 192.168.86.100
                  │            │
        ┌─────────┘            └─────────┐
        ▼                                ▼
  web1 192.168.86.7              web2 192.168.86.8
  Keepalived(MASTER)             Keepalived(BACKUP)
  ┌──────────────┐               ┌──────────────┐
  │ nginx :80    │               │ nginx :80    │
  │ php-fpm :9000│               │ php-fpm :9000│
  │ mariadb :3306│               │ mariadb :3306│
  └──────────────┘               └──────────────┘
        │
        └────────► zabbix 192.168.86.62（盯着上面三台）
```

## 环境

| 机器 | IP | 配置 | 装了什么 |
|---|---|---|---|
| zabbix | 192.168.86.62 | 2C / 4G / 60G | Zabbix Server 6.0 |
| web1 | 192.168.86.7 | 2C / 2G / 40G | Docker、Keepalived（MASTER） |
| web2 | 192.168.86.8 | 2C / 2G / 40G | Docker、Keepalived（BACKUP） |
| 虚拟 IP | 192.168.86.100 | — | 挂在 web1 上，web1 挂了飘到 web2 |

- 宿主机：Windows 11 + VMware Workstation 16 PRO，三台虚拟机都在 192.168.86.0/24
- 系统：CentOS 7.9
- 软件：Docker 20.10、Nginx 1.22、PHP 8.1、MariaDB 10.6、Keepalived 2.0

> VIP 用的是 192.168.86.100。

## TIP：

这些数字都是我自己三台虚拟机上测的，无法直接套用到生产环境中。
